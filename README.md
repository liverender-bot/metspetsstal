# МетСпецСталь — Лендинг продажи редких и легированных сталей

## Репозиторий
- GitHub: `liverender-bot/metspetsstal`
- Сайт: https://liverender-bot.github.io/metspetsstal/

## Файлы
- **index-dark-molten.html** — основной рабочий файл
- **index.html** — копия для GitHub Pages (обновлять перед push!)
- **reserv/** — все версии (v1–v39)

## Push на GitHub
```bash
copy /y index-dark-molten.html index.html
git add -A
git commit -m "описание"
git push
```

## Структура сайта

### 1. Top bar (36px, фиксированная)
- Часы работы | Телефон
- Иконки соцсетей: **МАКС** (34×34, приоритет) • WA • TG • VK (все квадратные, border-radius: 6px)
- Email

### 2. Навигация (fixed top-9, h-20)
- Прозрачная → тёмная при скролле

### 3. Hero
- Фото цеха с листами металла + градиентный оверлей
- Слева: заголовок, текст, кнопки
- Справа: загрузка заказ-наряда (drag & drop + поля: телефон, email, организация)

### 4. Stock info
- «Более 10 000 тонн на складах, доставка от 2 дней»

### 5. Основные марки спецсталей (4 группы × 2 марки)
- Элементы Менделеева (C, Cr, Ni… с %)
- История стали — выезжает снизу за 3с при наведении (эффект карты из колоды)
- Кнопка «Заказать» (правый нижний угол, появляется при наведении)

### 6. Services teaser
- Бесплатная консультация, порезка, термообработка

### 7. Каталог продукции (реальный сортамент)
- **Углеродистая сталь** — лист горячекатаный: ГОСТ 14637-89, 16523-97 — Ст3сп, Ст3пс
- **Конструкционная легированная** — прокат толстолистовой: ГОСТ 1577-93 — 20, 35, 45 (ГОСТ 1050), 40Х, 45Х (ГОСТ 4543), 65 (ГОСТ 14959)
- **Низколегированная повышенной прочности** — лист горячекатаный: ГОСТ 19281-89 — 09Г2, 09Г2С, 10Г2С1, 14Г2, 15ГФ, 15ХСНД, 10ХСДП, 10Г2Б, 10ХСНД, 15Г2СФ, 16ГС, 14Г2АФ и др.
- Все позиции — **листы толщиной 4–160 мм** (шкала толщины в карточках + плашка внизу секции)
